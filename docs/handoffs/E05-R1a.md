## What was built
- **`HeldBall`** is a sample-driven model; ADR 011 has the details.
  - **Spring follow:** the ball follows the finger on a spring.
  - **Charging:** spin charges by path turning, scaled by pace.
  - **Reversal:** turning the other way bleeds spin off first.
  - **Held spin:** it fades with a 2.5 s half-life.
  - **Straight below the threshold:** below the curve threshold (0.25) a throw is straight, and `curve_ready()` reports the sparkle state.
  - **The fling:** direction and power come from the held ball's velocity over 100 ms.
  - **Timing:** samples use event time, and `tick()` advances the model while the finger is still.
  - **Tuning:** every constant is in `tuning`, for R1b's panel.
- **Interface:** it keeps the existing gesture's interface (`begin`, `move`, `release`, `cancel`, `placement`, `charge`) and result keys, so `LaunchMapper.to_launch` is unchanged.
- **The lab still uses `flick_gesture.gd` until R1b,** so no journey or physics result changes in this session.
