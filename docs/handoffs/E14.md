- `src/procedural/random_streams.gd`: versioned Park–Miller integer streams for
  shops, rewards, lanes, bosses and effects; stable name-derived seeds, unbiased
  bounded draws, JSON-exact state and validated restoration. No engine-global RNG.

  eligible pool and eight authored target triples. Produces DivisionRun specs;
  sorted input pools make selection independent of catalogue ordering.
- Seven distinct rivals/rules, then a championship explicitly reusing an

  Invalid/insufficient pools fail explicitly, without retry loops or silent repeats.

  consumer must enforce reveal timing; this stage does not yet change the UI.

  targets and saved RNG continuation. Caller remains authoritative for victory.

## Second review and revision (2026-10-27)

Re-reviewed the Light-effort implementation against the design and E13 source
`5aac9d2`. E14 remains IN_PROGRESS; this is a corrected generator stage, not a
completed native campaign. No owner action is pending.

Defects corrected:
- Targets previously dropped at Division boundaries. Every target now exceeds the
  preceding match, including the last boss before endless.
- Championship repetition was implicit. Eight distinct bosses are now the default;
  seven plus an encountered championship rule requires the explicit boolean
  `championship_reuses_encountered_rule`. Boss identity uniqueness is separate from
  rule identity; the design does not prohibit two different bosses sharing a rule.
- Saved schedules previously trusted their shape and profile ID. Version 2 binds a
  canonical profile digest and verifies every Division/preview plus boss/lane RNG
  continuation against regeneration. Changed profiles, altered targets, malformed
  records and invalid RNG states are refused before extension. Recovery work is
  bounded at 256 Divisions; this is an explicit versioned limit, not infinite play.
- Seeds previously collided whenever separated by 2147483646. Stream derivation
  now hashes the decimal seed and stream name; schedules require JSON-exact seeds.
  This removes that systematic alias, not all possible finite-PRNG collisions.
- Invalid RNG draws now return -1 without mutation in release builds; RNG schema
  version 2 intentionally rejects old draft state. No released saves use E14 v1.
- Pool/compatibility-list ordering no longer changes generated records or digests.
