## Decisions
- **Unsold categories:** boss rules, lane conditions and kits are never sold. The validator requires pool weight 0, price 0 and resale 0, and requires a boss rule to name its counterplay.
- **Counter tags** for all nine are in the unlock registry now. `authored_test` checks that each already has an initially available item with a matching tag. When a League uses one of these rules, the graph's existing counter check applies to it as well.
- **Rival identities** (name, intro, reactions, first-clear reward) are not part of a rule. They come with League specs (a later E17 batch) and E21 presentation, which must map all 20 rules to rivals.
- **"Championship"** in the design's table is the existing policy of bringing back a rule already met, not a new rule.
