## What changed
**One menu, in the same shape everywhere.** The menu button opens a parent menu in a match and in the Clubhouse alike:

| Match | Clubhouse |
|---|---|
| Resume | How to Play |
| Throw Settings | Throw Settings |
| Sound & Effects | Sound & Effects |
| Clubhouse | Close |
| Restart Run | |

**Throw Settings and Sound & Effects are sibling pages of that menu:**
- "Options" is now named for what it is, Throw Settings.
- Sound & Effects is no longer a row inside Throw Settings.
- Each page ends with **Back**, centred, which returns to the menu that opened it, with focus on that page's entry. Escape does the same.
- On the menu, Resume (match) or Close (Clubhouse) leaves; Escape closes it too.

**Other behaviour:**
- The lane stays paused while a page is open from the match menu.
- The music still eases to half under either page, as it did under Options.
