# Agent task handoff — UI-19, a fresh seed for every run (owner, 2026-11-19)

## Assignment
- **Owner:** Claude, at the owner's request ("Yes, fix it"), after finding that every run entered from the League Board was run 1 with seed 1. Every player therefore saw the same shops, Licenses and draws for the same choices.
- **State:** DONE.
- **Branch:** `claude/roguewood-build`.
- **Paths:** src/bootstrap/bootstrap.gd; tests/run_seed_journey.gd (JSEED, new); tests/shell_smoke.gd (J01); tools/qa.py.

## What changed
**In the real game (`random_runs`), every new run:**
- draws its own random seed, which feeds the shop and deck streams as before;
- takes the next run number from the Career's run count.

That covers Enter League, New Run and Restart Run. Restart Run is now a fresh run, not a replay of the same one.

**Saved and restored runs:** the seed is saved with the run, as before, so a restored run carries on exactly where it left off.

**Unchanged:**
- **Tutorial:** keeps its fixed seed (its scripted lane needs it).
- **Test Campaign:** keeps seed = run number (ADR 009).
- **Journeys and the browser QA run:** keep seed = run number, so their shops stay reproducible.

## For tools and tests
- **JSEED** (`e2e --journey JSEED`, two stages) runs the real-game setting:
  - Enter League is run 1 with its own seed;
  - back to the Clubhouse, Enter League is run 2 with a different seed and shop stream;
  - Restart Run (pressed twice) is run 3 with another seed;
  - after a restart, Continue resumes run 3 with its saved seed;
  - the tutorial keeps its fixed seed.
- **J01** (which starts the game as a player does) now expects Restart Run to give the next run number, a new seed, and the score and Division back at the start.
