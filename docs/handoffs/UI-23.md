## The fade to the Clubhouse
**When it applies:** leaving a run for the Clubhouse, whether from the session menu's Clubhouse, the result sheet's Clubhouse, or the end of the tutorial. It is a slow fade of about 3.5 s:
1. **Fade out (1.5 s):** the screen fades to near-black. The run's music fades with it (the League's, or the ceremony's awards track). The run takes no input.
2. **Behind the dark:** the run closes and the Clubhouse is built. From here it takes input.
3. **Fade in (0.2 s hold, then 1.8 s):** the Clubhouse fades up, and its music rises from silence to its level.

**Edge cases:**
- Starting a new run during the fade-in simply lets the fade finish over it.
- Leaving again mid-fade picks up from the current darkness.

**Not included:** the title's "Tap to Play" and starting a run keep their current transitions; the request was for leaving to the Clubhouse.
