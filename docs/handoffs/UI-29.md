## Fix

- **The next run:** the player starts it from the Clubhouse with Enter League.

**Unchanged:**
- **A run with nothing to award:** its sheet keeps New Run or Retry beside Clubhouse.
- **The menu's Clubhouse entry:** goes through the awards to the Clubhouse, as before.
