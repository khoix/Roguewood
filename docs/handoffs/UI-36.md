# Agent task handoff — UI-36, the web loader on phones (owner, 2026-11-20)

## Assignment
- **Owner:** Claude, from the owner's play notes: "For the progress bar animation, the ball knocks over the pin on a desktop browser, but it appears to lag and rarely ever show on mobile."
- **State:** DONE.
- **Branch:** `claude/roguewood-build`.
- **Paths:** `tools/author_loader.py`, `export_presets.cfg` (its `html/head_include`, generated) and `tests/web/web_journey.mjs` (JW01).

## Why it failed on phones
- **The lag:** every frame of the ball's spin, bob and roll was set by JavaScript in `requestAnimationFrame`. While a phone compiles and starts the game, its main thread is busy, so those frames stalled.
- **The missing knockdown:**
  - A phone's download is often compressed with no known size. The engine then drops the progress bar's value, so the loader never reached 100% and the pin never fell.
  - The engine removes its loading overlay the instant the game starts. Even at 100%, the pin's fall was cut off.

## What changes for the player
- **Smooth on a busy phone:** the ball's spin and bob are CSS animations, and its roll is a CSS transition. JavaScript only says how far along it is. The browser keeps them playing while the game starts.
- **No known download size:** the ball rolls down the lane and knocks the pin over, again and again, until the game is ready.
- **The finale:** when the engine removes its overlay, the loader puts it back: the ball reaches the end, the pin falls, and after about 0.9 s the overlay fades out (gone at 1.4 s). Taps pass through to the game meanwhile.
- **Unchanged:** the look, the lane, the pixel ball and pin, and the engine's own progress bar (kept, invisible).
- `rwLoaderStart(overlay)` now takes the overlay it drives, so a test can run it on a stand-in while the real one is still in its finale.

## Tests

  - with the value removed, the loop's roll (`rw-run`) and knockdown (`rw-knock`) run;
  - after removal, the overlay is back with the pin down and taps passing through, then gone after 1.4 s.
