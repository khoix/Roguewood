## What changes for the player
- **How to Play** has three choices: Play Tutorial, **Practice** ("The House Ball, no items, endless games") and Talk the Talk.
- **Practice:**
  - ten Wood pins and the House Ball; no cards, Charms, money, shop, rival or rules;
  - the House look and music;
  - games of ten frames, each frame scored as in a run (Value × Mult);
  - after the tenth frame, **Next Game** starts the next game at once.
- **The top bar:** "Practice · Game N", the game's score, frames left, and the best game so far. The rival, Charms, money, card hand and fold bar are hidden.
- **Nothing counts:** like the tutorial, practice plays on a throwaway Career with saving off, at a fixed seed. Leaving (menu → Clubhouse) returns the League Board to the League chosen before; Restart Run starts practice again.
- **Throw Settings** no longer has the Practice toggle. E09's target-free Division remains as a test fixture (`ThrowSettingsPanel.use_practice()`), which the journeys that test their own subsystem use.

## How it works
- The content set "practice" is a one-Division League with ten-frame matches, ten Wood pins, an empty deck and no money. It is played in the Division's practice mode, which repeats a target-free match. The Division format's opener, feature, boss and rival only satisfy validation and never appear.
- `ThrowLab.practice_lane()` routes the match end to `_next_practice_game()` (no shop or payout), keeps each game's score for the best, and hides the panels.
- **Contract:** a frame's context `match_frame` may now be 1–10, for ten-frame practice games; items' `match_frame` conditions stay 1–8. CONTRACTS.md notes it.
